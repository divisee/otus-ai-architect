# Речевой канал: ASR, диаризация, TTS

## Статус

**Принято.**

| Слой | Решение | Примечание |
|------|---------|------------|
| ASR | faster-whisper, чекпоинт `large-v3-turbo`, `language=ru` | веса OpenAI, инференс в периметре |
| Резервный чекпоинт | `large-v3` на том же рантайме | при недостаточной точности терминов |
| Диаризация и выравнивание | WhisperX (faster-whisper, wav2vec2, pyannote) | Whisper не размечает говорящих самостоятельно |
| Телефония | разделение по каналам АТС | приоритет над ML-диаризацией |
| Сравнительный прогон | GigaAM-v3 e2e_rnnt | не промышленный стек |
| TTS | Silero | синтез в периметре |

Облачные Speech API не используются (ADR-0001).

## Контекст

Каналы: телефонная линия и файл wav. Требования: русский язык, термины МКБ, задержка на короткой реплике, разметка говорящих при числе участников больше одного. Идентификатор актора сессии определяется учётной записью и ACL, не тембром (ADR-0002).

Типовые ситуации: один пациент; стереозапись АТС; подключение оператора; законный представитель и ребёнок в одном помещении.

## Чекпоинты Whisper

На дату решения открытого Whisper v4 нет. Промышленные веса: `large-v3` и `large-v3-turbo` (дистиллят, декодер 32→4 слоя, около 809M параметров, порядка 6 ГБ VRAM против 10 ГБ у `large-v3`).

| Чекпоинт | Параметры / VRAM | Скорость | Применение |
|----------|------------------|----------|------------|
| tiny, base, small | низкие | высокая | отклонено: недостаточная точность |
| medium | средние | средняя | только отладка |
| large-v3 | ~1,5B / ~10 ГБ | ниже turbo | резерв |
| large-v3-turbo | ~0,8B / ~6 ГБ | выше large-v3 | принято |
| distil-whisper | ниже | выше | отклонено: ориентация на английский |

Рантайм: faster-whisper (CTranslate2). Это движок инференса того же чекпоинта, не отдельная модель.

По опубликованным сравнениям 2026 года на русском языке полный `large-v3` не обеспечивает стабильного выигрыша в WER относительно turbo при большей задержке. Переключение чекпоинта выполняется конфигурацией, без изменения оркестратора.

## Сравнение Whisper и GigaAM

Авторы GigaAM публикуют оценку side-by-side 70:30 относительно Whisper-large-v3 (LLM-as-a-Judge). Независимые измерения на русских записях (2026):

- на студийной речи turbo и GigaAM-v3 сопоставимы (WER около 7%);
- на шуме и нескольких говорящих преимущество у Whisper;
- на CPU GigaAM существенно быстрее; Whisper turbo без GPU не обеспечивает работу в реальном времени;
- встроенный VAD Whisper снижает качество (минус 3–4 п.п. WER); используется внешний VAD;
- нарезка речи на короткие изолированные фрагменты снижает WER примерно на 6 п.п.

В контуре выделен L40S (ADR-0004). Ограничение по CPU для Whisper не применяется.

| Критерий | Whisper large-v3 / turbo | GigaAM-v3 | Облачный STT |
|----------|--------------------------|-----------|--------------|
| Русский язык | достаточный | специализированный | достаточный |
| Шум, несколько говорящих | выше | ниже | — |
| Диаризация | конвейер WhisperX | отдельная сборка | — |
| Вкрапления латиницы | поддерживаются | слабее | — |
| VRAM | 6–10 ГБ | 2–6 ГБ | не применимо |
| 152-ФЗ | соответствует | соответствует | не соответствует |

Промышленный канал — Whisper. GigaAM сохраняется для сравнительных прогонов на корпусе клиники (телефон, коды МКБ, ФИО). При устойчивом преимуществе GigaAM не менее 2 п.п. WER решение пересматривается отдельным ADR. Дообучение Whisper в MVP не выполняется. После ASR применяется словарь замен (`узи` → УЗИ, числительные → коды МКБ).

## Диаризация

| Вариант | Условие | Решение |
|---------|---------|---------|
| Каналы АТС | промышленная телефония | приоритет |
| WhisperX и pyannote community-1 | монофоническая запись, оператор, двое в помещении | принято |
| pyannote 3.1 | недоступен community-1 | резерв |
| GigaAM transcribe_longform | сегментация по паузам (VAD) | не является диаризацией |
| Идентификация личности по голосу | биометрия | запрещено в MVP |

Веса pyannote хранятся во внутреннем реестре. Обращения к Hugging Face в runtime нет.

Идентификатор `SPEAKER_*` записывается в метаданные. Поле `actor_id` сессии не выводится из тембра.

## TTS

Принято: Silero. Whisper и GigaAM синтез не выполняют. Облачный TTS не используется.

## Размещение

Узел L40S: Whisper turbo (или large-v3), WhisperX, bge-m3. Реплика на вход модели подаётся после паузы не короче 500 мс либо целиком в окне модели. Искусственная нарезка на 3–4 с не применяется.

## Решение

1. ASR: faster-whisper `large-v3-turbo`, внешний VAD, `language=ru`.
2. Резервный чекпоинт: `large-v3`.
3. Говорящие: каналы АТС либо WhisperX.
4. GigaAM-v3 — только сравнительные прогоны.
5. TTS: Silero.

## Последствия

Ограничения: на CPU канал не предназначен. Галлюцинации на тишине снимаются внешним VAD.

## Проверка

Таблица WER на контрольном наборе записей: turbo, large-v3, GigaAM-v3. Контрольный файл с двумя говорящими через WhisperX. p95 ASR на реплике 5 с — не более 1,0 с на L40S.
