# Движок инференса LLM

## Статус

**Принято.** Единственный движок во всех средах — vLLM. Параллельный стек не вводится. Миграция на другой движок не планируется.

## Контекст

Модель: T-pro-it-2.1 (ADR-0003). Профиль нагрузки: повторяющиеся префиксы RAG, структурированные вызовы инструментов, конкурентность ниже 100 одновременных запросов. Требуются квантование (FP8 / AWQ) и управление KV-cache.

Карточка модели указывает SGLang как рекомендуемый рантайм (`--tool-call-parser qwen25`). Ниже варианты рассмотрены; выбран vLLM (`--tool-call-parser hermes`).

## Рассматриваемые варианты

| Движок | Преимущества | Ограничения | Решение |
|--------|--------------|-------------|---------|
| vLLM | PagedAttention, automatic prefix caching, FP8 и AWQ, OpenAI-совместимый API, TTFT при низкой конкурентности, единый контур метрик | на высокой конкурентности RAG уступает RadixAttention | **принято** |
| SGLang | RadixAttention, xGrammar; рекомендация карточки T-pro | отдельный контур наблюдаемости; второй набор конфигураций | **отклонено** |
| TGI | упрощённый деплой Hugging Face | ниже пропускная способность | **отклонено** |
| TensorRT-LLM | максимальная плотность на H100 | сборка 25–40 минут на версию модели | **отклонено** |

Основание выбора vLLM: один комплект конфигурации и метрик в разработке и промышленной среде; совместимость с LangGraph через OpenAI API; достаточный TTFT при целевой нагрузке (ADR-0004). Выигрыш SGLang проявляется при высокой конкурентности, которая для текущего контура не планируется.

## Решение

Развёртывание: vLLM на H100, FP8 (при отсутствии FP8 — AWQ INT4). Параметры: `enable-auto-tool-choice`, `--tool-call-parser hermes`, prefix caching, continuous batching. Маршрутизация моделей 32B и 8B выполняется перед vLLM (ADR-0003) и не образует второго движка инференса.

## Последствия

Ограничение: при последующем росте конкурентности пиковая эффективность на RAG-префиксах может быть ниже, чем у SGLang. Компенсация — горизонтальное масштабирование реплик vLLM, без смены движка.

## Проверка

p95 не более 8 с при 10 RPS на штатном префиксе. Доля синтаксически валидных JSON вызовов инструментов не ниже 95%.
