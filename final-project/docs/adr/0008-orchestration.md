# Оркестрация агентов

## Статус

**Принято.** Используется LangGraph (машина состояний). Линейные цепочки без явного состояния регламентом проекта не допускаются.

## Варианты

| Средство | Оценка | Решение |
|----------|--------|---------|
| LangGraph | состояние, повтор, HITL, условные переходы Router → Knowledge / CRM / Policy | принято |
| LlamaIndex Workflows | сопоставимая машина состояний | отклонено: хуже стыковка с выбранной схемой агентов |
| CrewAI, AutoGen | ниже контроль точки Policy | отклонено |
| Линейный скрипт | отсутствует явное состояние и условные переходы | отклонено |

## Решение

Узлы графа состояний: Memory → Router → Knowledge | CRM | Policy → Output Guardrails. Операции записи и отмены выполняются с interrupt (HITL). Контрольные точки состояния сохраняются в PostgreSQL.

Голосовой адаптер публикует то же входящее сообщение, что и текстовый канал. Отдельный граф состояний для речи не создаётся.
