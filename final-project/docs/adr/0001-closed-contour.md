# Хостинг LLM и контур обработки данных

## Статус

**Принято.** Развёртывание open-weight компонентов в периметре организации. Выбор конкретных моделей, GPU, хранилищ и голосового стека фиксируется в ADR-0003–ADR-0009.

## Контекст

Система обрабатывает речь, текст и сведения о пациентах, включая несовершеннолетних. В состав обрабатываемых данных входят персональные данные и сведения, составляющие врачебную тайну (323-ФЗ ст. 13; 152-ФЗ ст. 10).

Политика организации: контур on-premise / air-gapped. API OpenAI и Anthropic не используются.

Заказчик — медицинская организация с бюджетом на закупку GPU. Размещение модели у внешнего провайдера API не рассматривается. Аренда GPU-виртуальной машины допустима только при запуске собственного сервера инференса.

## Варианты

| Критерий | A. Облачный API LLM/STT | B. Self-hosted в периметре | C. Облачный API и анонимизация |
|----------|-------------------------|----------------------------|--------------------------------|
| 152-ФЗ, врачебная тайна | передача ПДн и аудио провайдеру | обработка внутри периметра | данные покидают периметр |
| Политика ИБ | не соответствует | соответствует | не соответствует |
| Голосовой канал | аудио у провайдера | ASR и TTS в периметре | маскирование снижает качество ASR |
| Стоимость | операционные расходы за токены и минуты | капитальные затраты на GPU | операционные расходы и стоимость слоя защиты |

## Решение

Вариант B. Средства фильтрации ввода и вывода размещаются внутри периметра и не используются как основание для внешнего API.
