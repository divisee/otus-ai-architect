# Внешние порты: телефония и МИС

Голосовой канал и учёт визитов — внешние системы. Оркестратор зависит от узких контрактов, не от вендора АТС или CRM.

## Телефония

АТС не входит в Control Plane. Адаптер речи потребляет аудио или готовый транскрипт и возвращает текст для синтеза.

| Поле контракта | Назначение |
|----------------|------------|
| `call_id` | корреляция сессии |
| `caller_id` | АОН → сопоставление с `actor_id`; иначе оператор |
| `audio` / `transcript` | вход ASR; на стенде без GPU допустим только транскрипт |
| `transfer_operator` | эскалация, не отдельный агентный граф |

Промышленный SIP/SBC — целевой адаптер (Deployment). В MVP вход — микрофон или файл; реализация АТС отклонена как отдельный продукт.

Идентификатор говорящего `SPEAKER_*` после диаризации пишется в метаданные и не назначает `actor_id` (ADR-0002, ADR-0009).

## МИС / запись

Внешняя система клиники — медицинская информационная система и расписание, не sales-CRM. Конкретный вендор не выбирается.

| Операция | Семантика |
|----------|-----------|
| `list_slots` | свободные окна услуги и филиала |
| `book` / `reschedule` / `cancel` | изменение визита после HITL |
| `get_patient` | карточка только после Policy |

Заглушка `backend/data/crm/seed.json` реализует тот же порт. Замена заглушки на промышленную МИС не меняет узлы LangGraph.
