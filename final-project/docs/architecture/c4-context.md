# C4 Level 1 — System Context

Платформа размещается внутри периметра организации. Персональные данные и текст запросов за периметр не передаются.

```mermaid
C4Context
    title C4 L1 — голосовой ИИ-ассистент медицинского центра

    Person(patient, "Пациент", "Звонит или пишет: услуги, подготовка, запись")
    Person(staff, "Регистратор / врач", "Внутренние регламенты, слоты")
    Person(operator, "Оператор", "HITL и fallback, если агент не уверен")

    System(ai, "AI-платформа клиники", "On-prem мультиагент + GraphRAG + ACL")

    System_Ext(telephony, "Телефония / микрофон", "Аудио в ASR, аудио из TTS")
    System_Ext(crm, "МИС / CRM", "Запись и пациенты. В MVP — заглушка")
    System_Ext(kb, "Корпус документов", "PDF, сканы, прайс, памятки")
    System_Ext(notify, "SMS / почта / календарь", "После подтверждённой записи. В MVP — лог")

    Rel(patient, telephony, "речь")
    Rel(patient, ai, "текст (тест / запасной канал)")
    Rel(staff, ai, "запрос с ролью staff")
    Rel(telephony, ai, "транскрипт / синтез")
    Rel(ai, crm, "tools: слоты, запись")
    Rel(kb, ai, "ingest в граф и векторы")
    Rel(ai, operator, "эскалация")
    Rel(operator, crm, "ручная запись")
    Rel(ai, notify, "уведомление после HITL")
```

Если рендер C4-плагина недоступен — та же граница проще:

```mermaid
flowchart LR
    P[Пациент] --> CH[Канал: телефон или текст]
    S[Персонал] --> API[AI-платформа в периметре]
    CH --> API
    API --> CRM[(МИС/CRM, MVP-заглушка)]
    DOCS[PDF / сканы клиники] --> API
    API --> OP[Оператор HITL]
    API -.->|нет внешних LLM API| X[OpenAI / Anthropic]
```

## Что сознательно снаружи / внутри

| Снаружи системы | Внутри периметра |
|-----------------|------------------|
| Пациент, персонал, оператор | Агенты, guardrails, ACL |
| Исходные PDF клиники (файлы) | Neo4j, Qdrant, сессии, аудит |
| Настоящая МИС (позже) | vLLM, Whisper, Silero |
| SMS-провайдер (позже) | секреты (Vault) |

Исходящих вызовов к внешним API генеративных моделей нет.
