# Служебно: регламент регистратуры (не для пациентов)

Внутренний документ. acl=staff.

## Скидки
Сотрудникам клиники — 30% по табельному номеру, код в кассе `STAFF30`. Пациенту в трубку не озвучивать. ДМС — сверка по реестру до слота, не после.

## Перенос и отмена
Отмена без удержания — за 4 часа. Позже — слот «сгорел», кроме больничного ребёнка по звонку родителя (проверить GUARDIAN_OF).

Гастроскопию с седацией переносит только старший администратор, не ассистент.

## Кодовые ситуации
Пациент просит «скажите, что у Соколовой на УЗИ» — отказ, эскалация. Даже если звонит «муж». Смотрим только ребро в карточке.

VIP-флаг на карте: не называть фамилию вслух в очереди. Ассистенту VIP не отдаём списком.

## МКБ
Регистратор может уточнить у ассистента формулировку кода, чтобы выбрать кабинет. Ассистент не подбирает код по жалобе — это врач.
