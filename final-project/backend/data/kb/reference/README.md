# Справочник МКБ-10

Файл `mkb10-parsed.csv` — иерархия кодов (code, name, parent, level), ~12 257 строк.

- Разбор публичного классификатора: [KindYAK/mkb-10-parsed](https://github.com/KindYAK/mkb-10-parsed)
- В проде холдинг подменяет выгрузкой НСИ Минздрава: `1.2.643.5.1.13.13.11.1005` ([nsi.rosminzdrav.ru](https://nsi.rosminzdrav.ru))

Это **терминологический слой GraphRAG**, не диагностический движок. Ассистент может сказать, как называется код из направления, и к какому врачу в клинике обычно идут с этим классом. Он не ставит код по симптомам.
