# Корпус типового медицинского центра

Синтетические документы гипотетической клиники. ACL задан в [`manifest.yaml`](manifest.yaml), не выводится моделью из текста.

| Папка | Кто видит |
|-------|-----------|
| `public/` | все |
| `staff/` | регистратор |
| `patient_anna/` | только Анна |
| `patient_misha/` | Анна как мать |
| `patient_boris/` | только Борис |
| `reference/` | МКБ-10, публичный справочник |

Полный классификатор не копируем в каждый чанк прайса: отдельные узлы `IcdCode` + векторный поиск по названию кода.
