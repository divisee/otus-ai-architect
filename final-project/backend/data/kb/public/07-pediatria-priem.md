# Педиатрический приём

Услуга PED-01, филиал Лесная, врач Белова И.С.

Записываем ребёнка на **карту ребёнка**. Звонит законный представитель (родитель, опекун), которого регистратура завела в карточку. Бабушка без доверенности и без связи в базе — к оператору.

На приём: свидетельство о рождении, полис, паспорт родителя, прививочный сертификат по возможности.

Температура выше 38,5 в день визита — лучше перенести, чтобы не сидеть в общем коридоре. Перенос — через ассистента с подтверждением.

Ассистент не ставит диагноз по симптомам («сыпь, что это»). Может записать к педиатру и прочитать код из уже выданного направления.
