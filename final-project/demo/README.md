# Демонстрационный стенд

Разговор с ассистентом в браузере: голосом или текстом, с разбором того, что
произошло внутри — маршрут, основание доступа, допущенный контекст, токены
персональных данных и запись в журнале.

Стенд поднимает **тот же оркестратор**, что и `/v1/chat`: интерфейс импортирует
`app.agents.orchestrator` напрямую, без копии логики. Проверка прав, запрет
диагноза и подтверждение записи выполняются кодом до обращения к модели —
подменить их выбором модели нельзя.

## Запуск

```bash
cd final-project
backend/.venv/bin/pip install -r demo/requirements.txt
backend/.venv/bin/streamlit run demo/app.py
```

Откроется `http://localhost:8501`. Данные стенда синтетические:
[`backend/data/crm/seed.json`](../backend/data/crm/seed.json).

## Кто формулирует ответ

| Режим | Что происходит | Когда выбирать |
| ----- | -------------- | -------------- |
| **Сборщик из репозитория** | ответ собирается из допущенных узлов и фрагментов кодом, модель не вызывается | запасной ход: работает без сети и ключей, показывает контракт доступа в чистом виде |
| **Локальная модель (Ollama)** | `ollama serve` на том же хосте, запрос никуда не уходит | **по умолчанию**, если Ollama поднята: ближе всего к промышленному контуру, так же работает vLLM в периметре |
| **Внешний API (OpenRouter)** | реплика и допущенный контекст уходят во внешний сервис | только для показа качества формулировок; в промышленном контуре запрещено ([ADR-0001](../docs/adr/0001-closed-contour.md)) |

Стенд сам проверяет, отвечает ли Ollama, и выбирает её. Если модель недоступна или ответила ошибкой, ответ соберёт код, а причина будет видна в панели «Что произошло внутри».

Ключ OpenRouter вводится в поле интерфейса и нигде не сохраняется. Если нужно не
вводить его каждый раз — `demo/.streamlit/secrets.toml`, этот файл в `.gitignore`.

Для Ollama: `ollama pull qwen2.5:7b` — модели 7B достаточно 48 ГБ оперативной памяти хоста.

## Промпт ассистента

Промпты лежат отдельными файлами в [`prompts/`](prompts/) и читаются на каждую
реплику: правка видна со следующего ответа, перезапускать стенд не нужно.
Отсутствие файла — падение на старте, а не пустой промпт.

Собирается из двух частей: общая — роль и границы, добавка — по каналу.
Права от канала не зависят, их проверяет код ([ADR-0002](../docs/adr/0002-acl-rebac.md)).

| Файл | Когда применяется |
| ---- | ----------------- |
| [`prompts/base.md`](prompts/base.md) | всегда |
| [`prompts/voice.md`](prompts/voice.md) | звонок, ответ уходит в синтез речи |
| [`prompts/chat.md`](prompts/chat.md) | чат на сайте |

Чего в промпте намеренно **нет**: правил доступа. Отказ по чужой карте и отказ
в диагнозе формулирует код до обращения к модели — их нельзя переубедить
инструкцией ([`app/guardrails/output.py`](../backend/app/guardrails/output.py)).

### `prompts/base.md` — роль и границы

```text
Ты — голосовой помощник справочной службы медицинского центра.
Ты не врач и не ставишь диагноз.

КАК ГОВОРИТЬ
— Обращайся на «вы», спокойно и доброжелательно, как внимательный администратор
  на ресепшене. Без официоза и без панибратства.
— Говори о деле с первой фразы. Не представляйся заново, не благодари за
  обращение, не рассказывай, что ты искусственный интеллект.
— Одна мысль — одна фраза. Не перечисляй всё, что знаешь: назови то, о чём
  спросили.
— Извиняйся не больше одного раза и только по делу.
— Ты и есть та линия, на которую обратились. Не предлагай перезвонить, не
  отправляй на сайт и никуда, кроме оператора регистратуры.
— Если в вопросе не хватает ясности — филиал, дата, кто из членов семьи, —
  задай один короткий уточняющий вопрос вместо догадки.
— Если человек жалуется на самочувствие, посочувствуй одной фразой и сразу
  передай разговор оператору: советов не давай.

ЧТО МОЖНО ГОВОРИТЬ
— Только то, что есть в блоке КОНТЕКСТ. Ничего не додумывай и не округляй:
  цены, часы подготовки и даты называй ровно как в контексте.
— Цена принадлежит той услуге, рядом с которой она стоит в строке контекста.
  В контексте несколько услуг — не переноси цену с одной на другую и не
  складывай их. Не уверен, о какой услуге спрашивают, — переспроси.
— Не хватает сведений — так и скажи и предложи соединить с оператором
  регистратуры.
— Диагноз не ставь и коды МКБ не толкуй. Код из уже выданного направления
  можно прочитать так, как он там записан.
— Внутренние обозначения услуг вроде USI-01 или PED-01 вслух не произноси:
  называй услугу словами.
— Токены вида [PHONE_0] и [NAME_0] оставляй как есть — значения подставит
  система.
```

### `prompts/voice.md` — телефонный разговор

```text
ЭТО ТЕЛЕФОННЫЙ РАЗГОВОР
Твой ответ будет озвучен вслух, человек его не видит.
— Две короткие фразы, самое большее три. Никаких списков, таблиц, разметки,
  ссылок, скобок и символов ₽, №, %.
— Числа, даты, время и деньги пиши словами так, как их произносят:
  «три тысячи двести рублей», а не «3200 ₽»; «восемнадцатого сентября»,
  а не «18.09.2026»; «в восемь утра», а не «08:00»; «шесть часов», а не «6 ч».
— Сокращения разворачивай: «УЗИ органов брюшной полости» вместо «УЗИ ОБП»,
  «гастроскопия» вместо «ЭГДС». Саму аббревиатуру УЗИ произносить можно.
— Перед записью проговори услугу, день, время и филиал и спроси подтверждение
  одной фразой.
— Вопрос в конце уместен, только если он двигает разговор дальше: предложить
  запись, уточнить филиал или дату. Если на вопрос уже отвечено полностью —
  просто закончи. Вопрос ради вопроса не задавай и точку на вопросительный
  знак не меняй.
```

### `prompts/chat.md` — чат на сайте

```text
ЭТО ЧАТ НА САЙТЕ
— Две-три фразы. Цены, даты и время оставляй цифрами.
— Сокращение раскрывай при первом упоминании.
— Списком отвечай только там, где перечисляются свободные окна.
```

Что даёт голосовая добавка:

| | без неё | с ней |
| --- | --- | --- |
| дата и время | `18.09.2026 после 8:00` | «восемнадцатого сентября, после восьми утра» |
| цена | `3200 ₽` | «три тысячи двести рублей» |
| услуга | `УЗИ ОБП, USI-02` | «УЗИ органов брюшной полости» |
| длина | абзац со списком | две фразы и короткий вопрос |

## Речевой канал

Распознавание — **faster-whisper** на CPU: тот же Whisper, что в
[ADR-0009](../docs/adr/0009-voice-whisper-diarization.md), только маленький
чекпоинт вместо `large-v3-turbo`. Синтез — штатный голос macOS Milena. Звук с
машины не уходит ни на одном шаге.

Чекпоинт скачивается при первом включении: `tiny` ≈ 75 МБ, `base` ≈ 145 МБ,
`small` ≈ 480 МБ. На медицинских словах заметно выигрывает `small`.

## Сценарии

Кнопки в интерфейсе прогоняют то, что заявлено в архитектуре:

| Сценарий | Что показывает |
| -------- | -------------- |
| Открытые материалы | ответ из графа услуг, основание `public` |
| Доступ по опеке | карта ребёнка открыта матери, основание `guardian` |
| Отказ в диагнозе | запрос закрыт до обращения к модели, узлы пусты |
| Отказ по доступу | чужая карта не попадает в контекст модели, а не попадает и остаётся непересказанной |
| Запись с подтверждением | визит фиксируется только после «да» |
| Токенизация ПДн | телефон заменён токеном, видно реплику глазами модели |
| Обязанности регистратуры | сотрудник видит визит и код направления, но не документы карты |

Панель «Что произошло внутри» на каждой реплике показывает допущенные узлы и
фрагменты, найденные персональные данные, **точный текст, ушедший в модель**, и
запись журнала по `request_id`. Основание в журнале одно главное — самое узкое
из сработавших, — а рядом перечислены все.
